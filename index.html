Project 02 · 2026 · Live

Nihongo Dōjō

I built the app I needed to learn Japanese

Role
Sole designer and developer
Stack
  • Vanilla JS
  • ES Modules
  • Canvas API
  • PWA
  • Service Worker

A progressive web app for learning Japanese, written in vanilla JavaScript with zero dependencies. The part I am proudest of: handwriting practice on a canvas, scored by comparing the drawn pixels against the reference glyph — precision × coverage combined into an F1 score — plus stroke-count validation, because in Japanese the order and number of strokes is part of the character. It also does spaced repetition, kana, N5 kanji, grammar, counters, and a printable survival sheet. Fully installable and usable offline.

  • 10+learning modules
  • 0dependencies
  • 100%works offline

Role
Game design, programming, pixel art
Stack

A 2D metroidvania set in a kingdom swallowed by night. No dialogue, no tutorial — everything the player needs to understand is carried by level design, animation, and sound. Currently a playable prototype of 14 interconnected rooms. This is where I learn game feel: how many frames a jump should hang, how far a hit should push you back, how silence builds tension.

Project 04 · 2026 · In progress

Jarvis

A voice assistant that remembers and acts

Role
Architecture, development, interface design
Stack
  • Electron
  • Python
  • Claude API
  • Speech-to-text
  • Web Audio API

Not a chatbot — a copilot. A desktop voice assistant built on Electron and Python that keeps persistent memory across sessions and can actually act on the machine rather than only answering. The interesting problems here are not the model calls: they are latency, interruption handling, and designing a voice interface that does not make you wait.

Role
Design and development
Stack
