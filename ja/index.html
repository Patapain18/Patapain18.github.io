Astero

プロジェクト 02 · 2026 · 公開中

Shinka 進化

水槽のガラスの前に立ち、通り過ぎる命を眺める

担当
コンセプト・アートディレクション・開発
技術
  • Three.js
  • WebGL
  • Web Audio API
  • Blender
  • Python
  • GLSL

静かに眺めるための 3D サイトです。大きな水槽のガラスの前に立ち、通り過ぎる命を見つめます。九つの種が視界を横切り、よく現れるものもあれば、ほとんど現れないものもあります。希少度は訪問者の実際の時刻に従い、夜にはクラゲが光り、別の種が姿を見せます。捕まえることはしません。カーソルを動物に留めて観察すると、図鑑に加わります。動物は Blender のスクリプトで生成しました — 形状、点ごとに計算した皮膚、生体力学として書いた泳ぎ。音楽以外のすべての音は Web Audio でリアルタイムに合成しています。学んだこと：ほとんど何も起きない場所を設計し、それで十分だと言えるようにすること。

  • 9種 — イワシからジンベエザメまで
  • 0録音した効果音 — すべてリアルタイムで合成
  • 4段階の希少度 — 訪問者の実際の時刻に連動

プロジェクト 03 · 2026 · 完成

WeatherHub

空をGPUが描く、ネイティブの天気アプリ

担当
設計・開発
技術
  • Swift
  • SwiftUI
  • Metal
  • MapKit
  • Open-Meteo API

Swift と SwiftUI で作った macOS 向け天気アプリです。データは Open-Meteo。予報、お気に入りの都市、UV と大気質、太陽の軌跡、スポーツ施設の地図、そして「今日は走る日か」を教えてくれる、しきい値を調整できるスポーツプロファイル。いちばん力を入れたのは空です。19 の気象条件（うち 10 は極端な状態）を Metal で描画し、天気を「読むラベル」ではなく「動きを眺めるもの」にしました。学んだこと：ネイティブアプリは、データのない画面、エラー、コントラストのひとつひとつまで、最後まで仕上げることを強いてきます。

  • 19GPUが描く空の状態
  • 8種目 — それぞれ自分のしきい値で評価

Cypher&co

テーマ・3Dシーン・デザイン・開発
技術

  • PHP
  • Three.js

架空のスパイ機関のための WordPress サイトです — 四人のエージェント、ガジェットのショップ、事件ファイル — テーマはゼロから書きました。ページはそれぞれ Three.js で描いた部屋です。WordPress のデータベースから事件ファイルが出てくる捜査官のオフィス、大きな赤いボタンを押すと連絡先が現れるサーカスのテント、ガジェットの工房。すべて同じシネマティックなパイプライン — AgX、アンビエントオクルージョン、ブルーム、フィルムグレイン。その周りに、監視カメラの HUD、「機関のターミナル」風のイントロ、ページ間のクロスフェード、WebGL のリキッドグラスエンジン、そして二つのイースターエッグ：シーザー暗号とコナミコマンド。学んだこと：CMS は、サイトのあり方を制限しません。

  • 33Dの部屋、ページごとに一つ
  • 2解読するイースターエッグ

プロジェクト 05 · 2026 · 完成

Signaux actions

信じる前に測る、株式シグナル

担当
設計・開発
技術
  • Python
  • pandas
  • WebGL2
  • GLSL
  • PyObjC
  • yfinance

Python で作った株式シグナルのシステムです。2026年4月、暗号資産のボット（グリッド、スキャルピング、機械学習）と、それらを比較するバックテストエンジンから始まりました。今は、米国の大型株49銘柄を5分ごとにスキャンし、モメンタムとテクニカルな状態で順位をつけるボットになっています。注文は出しません。売買は自分の手で行います。ダッシュボードは macOS のネイティブアプリで、メイン画面はひとつの部屋です — 素の WebGL2 で描いた街の前に、ガラスのパネルが五枚浮かび、実際の太陽とその影、流れる雲が映ります。いちばん誇りに思っているのは検証です。すべての順位付けを1取引日ずつ再生し、同じシグナルを別の銘柄に割り当てた200通りのシャッフルと比べます。自分のスコアには予測力がないと分かり、ダッシュボードはそれをそのまま表示しています。学んだこと：測っていないシグナルは、ただの意見です。

  • 49銘柄 — 米国の大型株を5分ごとにスキャン
  • 200通りのシャッフルと比較 — 同じシグナルを別の銘柄に割り当てたもの
  • 0件 — ボットは注文しない。判断は自分の手で
